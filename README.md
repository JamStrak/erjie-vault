# 二姐小金库

手机入口：<https://jamstrak.github.io/erjie-vault/>

供二姐杂货铺两位合伙人使用的单设备手机账本。先由一人记账，另一人查看导出的余额摘要或 CSV；没有账户、服务器账目数据库或实时同步。

本地预览需要用下面的开发服务器打开页面；直接双击 `index.html` 的 `file://` 地址不适合记账。正式在手机上使用时，请从 iPhone Safari 打开上方网址并添加到主屏幕。之后固定从主屏图标录入，避免浏览器与主屏应用各自形成一本账。完整操作见 [使用说明.md](使用说明.md)。

账目保存在浏览器本机存储。每次出摊后导出完整 JSON，在手机“文件”中确认文件存在；CSV 用于核对，不能用于恢复。程序源码可以公开托管，真实账目数据无需上传到源码仓库。

本项目无运行依赖。运行 `npm test` 检查核心记账规则。开发预览可用 `python -m http.server 22861 --bind 127.0.0.1`；该本地地址只供电脑调试，不是给手机长期使用的入口。
