# 二姐小金库

手机入口：<https://jamstrak.github.io/erjie-vault/>

供二姐杂货铺两位合伙人使用的单设备手机账本。先由一人记账，另一人查看导出的经营摘要或 CSV；没有账户、服务器账目数据库或实时同步。

首页先看**累计经营盈亏**，再看金库现金、按进价计的未售库存、代收待转入和个人垫付待报销。两人的正式净出资与待报销垫付分别列出，避免把个人垫资误算成共同出资。销售时填这次卖掉的商品进价，盈亏按“销售＋其他经营收入－已售商品成本－其他费用－报损”计算；进货后尚未卖出的商品仍是库存。旧账或暂不清楚成本的销售会提示“待核算”，从明细补齐后才显示准确盈亏。

本地预览需要用下面的开发服务器打开页面；直接双击 `index.html` 的 `file://` 地址不适合记账。正式在手机上使用时，请从 iPhone Safari 打开上方网址并添加到主屏幕。之后固定从主屏图标录入，避免浏览器与主屏应用各自形成一本账。完整操作见 [使用说明.md](使用说明.md)。

账目保存在浏览器本机存储。每次出摊后导出完整 JSON，在手机“文件”中确认文件存在；CSV 和文字摘要用于合伙人核对，不能用于恢复。程序源码可以公开托管，真实账目数据无需上传到源码仓库。

本项目无运行依赖。运行 `npm test` 检查核心记账规则。开发预览可用 `python -m http.server 22861 --bind 127.0.0.1`；该本地地址只供电脑调试，不是给手机长期使用的入口。
